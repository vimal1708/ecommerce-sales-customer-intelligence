# Power BI Dashboard

This folder contains the Power BI dashboard for the E-Commerce Sales & Customer Intelligence project.

**Download the Power BI dashboard (.pbix): https://drive.google.com/file/d/1IfvEZfGUAykesLZzvRzrwlcbnij3RFcW/view?usp=sharing

The dashboard covers sales KPIs, monthly sales trends, payment methods, product categories, customer review scores, and customer geography.
